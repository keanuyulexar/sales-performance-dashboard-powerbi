# Sales Performance Dashboard using Power BI

## Project Overview

This project presents an interactive Sales Performance Dashboard built using Microsoft Power BI. The dashboard analyzes retail sales data from the Superstore Sales Dataset and provides insights into business performance through KPIs, visualizations, and interactive filters.

This project was completed as part of the **AnalystLab Africa Data Analytics Internship – Week 4**.

---

## Objectives

* Analyze sales performance
* Build interactive dashboards
* Create business KPIs
* Communicate insights through data storytelling

---

## Tools Used

* Microsoft Power BI
* DAX (Data Analysis Expressions)
* Superstore Sales Dataset

---

## Dashboard Features

* Total Sales KPI
* Total Profit KPI
* Total Orders KPI
* Profit Margin KPI
* Sales by Category
* Sales by Region
* Sales Trend Analysis
* Customer Segment Analysis
* Interactive Slicers
* Professional Dashboard Layout

---

## Key Insights

* Identified top-performing product categories.
* Compared regional sales performance.
* Analyzed sales trends over time.
* Measured overall profitability using KPIs.
* Built an interactive dashboard for business decision-making.
